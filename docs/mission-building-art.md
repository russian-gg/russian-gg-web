# Mission building prompts

One prompt per mission. Each makes a single building on a small grass island, in the style of
`russian-gg-web/src/assets/images/missionBg.webp`.

## How to use

1. Open Gemini or ChatGPT (or Leonardo / Firefly), start a new chat.
2. Upload `missionBg.webp` and send the **style message** below once.
3. Then paste the prompts one at a time in the same chat, so every building keeps the same style.
4. Remove the background (Leonardo built-in, Photopea "Remove BG", or `rembg`), keep the grass island.
5. Save as square `.webp`, about 512×512, with the file name shown, into
   `russian-gg-web/public/images/missions/`.

**Style message (send once, with the reference image):**

> This image is the art style for a set of 40 game map pieces. For every request I send next, draw ONE isometric 3D game-style building in exactly this style: same soft warm daylight, same colour palette, same rounded clean shapes, same level of detail. The building stands alone on a small round grass island with a short stone path, a few flowers and one small tree. Square 1:1, centered, plain white background, no text or letters anywhere (signs use simple icons only), no people. Reply with only the image.

If a tool forgets the style partway, re-upload the reference and resend the style message.

## Map background (send in the same chat)

**field-desktop.webp** (16:9)
> Now draw a top-down view of a wide green meadow for a game level map in the same style: a winding sandy dirt path from bottom-left to top-right with gentle curves, trees and bushes in small groups, wildflowers, a few rocks, a small river with a wooden bridge in one corner, soft white clouds at the top edges. No buildings, no text, no people. Wide 16:9.

**field-phone.webp** (9:16)
> Same meadow, but tall 9:16: the sandy path winds from the bottom upward in an S shape to the top. No buildings, no text, no people.

**Leave room for the buildings:** paths with wide, empty grass bends work best. The buildings are placed on top of the path in the app, so the background must stay empty.
