# Game companion assets

Tez gapir and Error hunt use separate game asset sets based on the original lesson mascot references. Other games and lessons keep their original source images. Outputs use 512px WebP with alpha preserved for lightweight UI use.

The Tez gapir assets below were generated with the built-in image generation tool. The Error hunt assets and their generation status are recorded separately at the end of this document.
