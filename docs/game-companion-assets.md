# Game companion assets

These game-only assets were generated with the built-in image generation tool from the existing lesson mascot references. Lesson source images remain unchanged. Outputs were converted to 512px WebP with alpha preserved for lightweight UI use.

## penguin

- Asset: `public/games/characters/penguin.webp`
- Reference: `public/characters/pingvin.webp`

Prompt:

Use case: stylized-concept. Production game companion sprite for a Russian language speaking mini-game. Redesign the reference teaching mascot as an energetic arcade game teammate, not a teacher. Keep the same recognizable species, face identity and polished friendly 3D cartoon material style. One character only, full body centered on a square canvas, filling about 85% of frame, clear silhouette legible at 72px, feet and accessories fully in frame. Genuine transparent background, no scene, no floor, no text, logos, watermark, books, pointers or classroom items. Clean premium mobile-game rendering, soft studio light, playful confident welcoming expression, dynamic but readable pose. Black-and-white plump penguin with orange beak/feet and round glasses. Replace navy teacher suit with a cobalt blue lightweight sporty arcade jacket, matching blue sneakers and small microphone headset. Friendly grin, one flipper lifted in a celebratory fist, slight forward ready-to-play stance.
